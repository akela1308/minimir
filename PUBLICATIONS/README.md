# Тексты для публикации: результаты протокола B

Готовые тексты по итогам второго эксперимента «мини-мира» (протокол B1-100k-v1,
данные с 10 по 29 сентября 2026, разбор в `REPORT_B.md`, страница результатов
<https://minimir.ilinmaks.com/results-b.html>).

| файл | куда | язык | объём |
|---|---|---|---|
| `linkedin.md` | LinkedIn, Facebook, Telegram | RU и EN | пост, около 2000 знаков |
| `medium.md` | Medium, Habr, личный блог | RU и EN | статья, около 1500 слов |
| `devto.md` | dev.to, Hashnode | RU и EN | статья с инженерным уклоном, около 1100 слов |
| `reddit.md` | r/MachineLearning, r/artificial, r/alife, r/evolution | RU и EN | четыре варианта поста |

Общие правила для всех текстов, чтобы не расходились между площадками:

1. Ни один текст не заявляет подтверждения главной гипотезы. Подтверждена
   только абляция (H-B4). Это не скромность, это то, что написано в
   предрегистрации.
2. Числа берутся только из `REPORT_B.md`. Если в тексте появляется новое
   число, его сначала надо получить из `runs/daily/protocol_b.jsonl`.
3. Восемь выживших миров это выборка, прошедшая отбор на выживание. Нельзя
   писать «обучение ускорилось в мирах со сменой правила», не упомянув, что
   речь о выживших.
4. Длинных тире нет ни в одном тексте.
5. Ссылка всегда одна и та же: страница результатов на сайте. Из неё уже
   ведут ссылки на предрегистрацию, полный отчёт и код.

Порядок публикации, который я бы советовал: сначала страница на сайте (уже
опубликована), затем LinkedIn, через день Medium, затем dev.to, и только после
этого Reddit. На Reddit приходят читатели, которые идут проверять ссылки, и
лучше, когда к этому моменту всё остальное уже стоит на месте.
